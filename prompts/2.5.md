Deux étapes : d'abord installer le plugin (commandes Claude Code, hors prompt classique), ensuite demander le composant `<Board>` (un seul prompt).

---

## Étape 1 — Installer le plugin `frontend-design`

Le plugin est maintenu par Anthropic dans le marketplace officiel `claude-plugins-official`. **L'install est au scope utilisateur** : elle vit dans `~/.claude/plugins/`, pas dans le repo. Tu n'auras donc rien à commiter pour cette étape.

Dans Claude Code (ouvert dans `game-of-life/`), exécute :

```text
/plugin marketplace add anthropics/claude-plugins-official
/plugin install frontend-design@claude-plugins-official
```

Vérification rapide depuis le terminal :

```bash
jq 'has("frontend-design@claude-plugins-official")' \
  < <(jq '.plugins' ~/.claude/plugins/installed_plugins.json)
# attend : true
```

Si `true`, le plugin est installé. Continue.

---

## Étape 2 — Composant `<Board>` (un seul prompt à Claude)

Voici l'objectif : la page d'accueil de `game-of-life` doit afficher une grille rendue par un composant React `<Board>`, qui consomme le moteur `src/core/grid.ts` posé en §2.3.

Copie-colle ce prompt dans Claude Code :

> Crée le composant React `src/components/Board.tsx` qui rend visuellement une grille du Game of Life. Contraintes :
>
> - **Props** : `{ grid: Grid }`, où `Grid` est importé de `@/core/grid`.
> - **Rendu** : une `<div>` racine par ligne, une `<div>` par cellule (cellule vivante = fond noir, morte = fond blanc, bordure grise fine). Utilise Tailwind v4. Aucune logique métier dans le composant : juste de la présentation.
> - **Composant pur** : ne mute jamais `grid`. Pas d'état interne, pas de hook.
> - Ensuite, modifie `src/app/page.tsx` pour rendre `<Board grid={seed}/>`. Le `seed` est **le plateau de jeu** :
>   - Déclare `const BOARD_SIZE = 30` à la racine du module.
>   - Construis-le via `createGrid(BOARD_SIZE, BOARD_SIZE)` (importé de `@/core/grid`, §2.3).
>   - Place un blinker (3 cellules vivantes alignées) **centré** dans ce plateau.
>   - Pourquoi 30×30 et pas 5×5 : le plateau a une taille fixe indépendante du pattern. Un blinker doit avoir de l'air autour pour qu'on observe l'évolution, et la même grille accueillera plus tard d'autres patterns (glider, pulsar… §3.2).
>
> Garde la page sobre.
>
> La skill `frontend-design` doit se déclencher automatiquement (mot-clé « composant React »). Si elle ne propose pas un rendu Tailwind sobre, demande-lui de simplifier.

> Tests UI co-localisés : on les introduira en §3.x quand une vraie logique d'interaction le justifiera. Pour l'instant, `<Board>` est purement présentationnel et son comportement est validé par le check d'intégration ci-dessous + l'œil.
