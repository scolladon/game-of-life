## Recommandations Serena

- `find_symbol("getPattern")` avant de toucher à `patterns.ts` — lis seulement le symbole concerné.
- `find_referencing_symbols("PATTERN_NAMES")` pour mesurer l'impact avant de modifier l'API.
- `replace_symbol_body` pour réécrire une fonction sans toucher au reste du fichier.

## Points de vigilance

- **Immutabilité** : `parseRle` doit retourner une nouvelle `Grid` à chaque appel (pas de cache mutable partagé).
- **Pas de `any`** — utilise des types stricts. `unknown` + narrowing si besoin.
- **Conventions Conway** : pour la Gosper Glider Gun, partir du RLE canonique (cf. conwaylife.com/wiki/Gosper_glider_gun). Si la grille fait > 40 colonnes, c'est normal.
- Le RLE peut avoir une dernière ligne sans `$` — pense au `!` final.
- **Whitespace dans le body RLE** : le format canonique n'en a pas (le séparateur entre digit et lettre n'existe pas, `3o` n'est jamais écrit `3 o`). Ne pas écrire de test qui s'attend à un parsing tolérant aux espaces internes — sinon il faudra réordonner la consommation du run avant le switch, ce qui rajoute une branche pour zéro vrai cas d'usage.

## Atteindre 100 % de couverture sur core/

Les branches non triviales à ne pas oublier :

- **`grid.ts` — `getDimensions(grid: Grid)` avec une grille vide** : la branche `height === 0` (qui renvoie `width = 0`) n'est jamais visitée par les tests "métier". Ajoute un test explicite :
  ```ts
  it('given empty grid when getDimensions then width is 0', () => {
    expect(getDimensions(createGrid(0, 0))).toEqual({ width: 0, height: 0 });
  });
  ```
- **`rle.ts` — ligne blanche entre header et body** : le `continue` sur `trimmed.length === 0` n'est exécuté que si l'entrée a une ligne vide. Couvre-la avec :
  ```ts
  parseRle('x = 2, y = 1\n\n\n2o!')   // doit retourner ['OO']
  ```
- Lance `npm run test:coverage`, puis ouvre `coverage/index.html` (ou inspecte `coverage/coverage-summary.json` par fichier) pour identifier les branches restantes au lieu de tâtonner.
