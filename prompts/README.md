# prompts — bouée de secours

Pour chaque sous-bloc avec checkpoint, ce dossier contient le prompt que vous
pouvez copier-coller dans Claude Code si vous êtes bloqué.

**Règle d'or** : essayez d'écrire votre propre prompt en premier (5 min
minimum). Le prompt fourni ici est une référence, pas une dictée.

Workflow conseillé :
1. Lire le titre du sous-bloc (slide concept en cours).
2. Écrire votre propre prompt → l'exécuter dans Claude Code.
3. Lancer `npm run check:X.Y` pour valider.
4. Si bloqué après quelques essais : ouvrir `prompts/X.Y.md`.
5. Adapter, exécuter, valider.
